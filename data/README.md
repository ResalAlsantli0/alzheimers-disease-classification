# Dataset setup

1. Download the [Alzheimer's Disease Dataset](https://www.kaggle.com/dsv/8668279) from Kaggle.
2. Rename the downloaded CSV to `alzheimer_disease_patient.csv`.
3. Place it in this directory.

Expected path:

```text
data/alzheimer_disease_patient.csv
```

Dataset files are ignored by Git so the source license and distribution terms remain attached to the original Kaggle publication.
